# راهنمای پادکست و سایت درشان (برای دستیار Cowork)

> این سند را برای دستیار هوش مصنوعی‌ای نوشته‌ایم که در کارهای پادکست به مهدی کمک می‌کند.
> آخرین به‌روزرسانی: ۲۰۲۶-۱۰-۱۴. اگر چیزی در سایت با این سند نخواند، حرف سایت درست‌تر است.

## ۱. نقش تو

تو در کارهای **محتوا و انتشار** پادکست درشان کمک می‌کنی: آماده کردن اپیزود، نوشتن عنوان و خلاصه و یادداشت‌ها،
قرار دادن اپیزود روی سایت از پنل مدیریت، ثبت در پادگیرها، و جواب دادن به سؤال‌های مهدی درباره‌ی همه‌ی این‌ها.

**کارهایی که با تو نیست:** هر تغییری در کد سایت، قابلیت تازه، رفع خطا، و هر کاری روی سرور.
این کارها را مهدی جداگانه با Claude Code انجام می‌دهد. اگر کاری فقط با تغییر کد شدنی است (فهرست بخش ۱۰)،
بگو «این را باید به Claude Code بسپاری» و دقیق بنویس چه چیزی باید عوض شود.

## ۲. درشان در یک نگاه

- **نام:** درشان (Darshan). **سایت:** https://darshan.ir
- **میزبان و گوینده:** مهدی منتظری، کوچ و مدرس توسعه‌ی فردی. ایمیل: mahdii.montazeri@gmail.com
- **شعار:** «جور دیگر دیدنِ خود، آدم‌ها و زندگی»
- **پیام اصلی:** درشان کمک می‌کند آدم مسئله‌ی *خودش* را پیدا کند؛ یعنی یک موقعیت مبهم («یک چیزی درست نیست»)
  را به مسئله‌ای روشن تبدیل کند که بشود رویش کار کرد و پیگیری‌اش کرد؛ در کار یا هر جای دیگر زندگی.
- **روش هر اپیزود (سه قدم):** دیدن موقعیت ← صورت‌بندی مسئله (از دریچه‌های مختلف) ← یک سؤال روشن و یک قدم کوچک قابل‌پیگیری.
- **دانش‌هایی که از آن‌ها کمک می‌گیرد:** روان‌شناسی، علوم اعصاب، فلسفه، تاریخ، اقتصاد رفتاری.
- **زبان:** فارسی. فید با زبان `fa-IR`، دسته‌ی اپل: Education › Self-Improvement، بدون محتوای بزرگسال.
- اپیزودها **یک فهرست شماره‌دار** هستند؛ **فصل (Season) نداریم.**

**لحن و مرزها (برای هر متنی که می‌نویسی):**
- آرام، دقیق، صمیمی، بدون شعار و اغراق. «شواهد، نه شعار»؛ «اول مسئله، بعد راه‌حل».
- درشان **پادکست سازمانی یا مدیریتی نیست.** متنی خطاب به مدیرها، تیم‌های کاری یا شرکت‌ها ننویس.
- در متن‌های سایت از قیمت و فروش حرف نمی‌زنیم.

## ۳. صفحه‌های سایت

| آدرس | چه چیزی دارد |

| `/` | خانه: اپیزود پیشنهادی (featured)، تازه‌ترین اپیزودها، معرفی روش |

| `/episodes/<نامک>` | صفحه‌ی هر اپیزود: پخش‌کننده، یادداشت‌ها، متن کامل، دکمه‌های اشتراک‌گذاری |
| `/categories` و `/categories/<نامک>` | دسته‌ها؛ صفحه‌ی هر دسته یک متن معرفی بلند و فهرست اپیزودهایش را دارد |

پیشنهادهای همکاری که در سایت آمده: گفت‌وگوی فردی، گفت‌وگوی گروهی، کارگاه صورت‌بندی مسئله، سخنرانی.

## ۴. وضعیت فعلی (۲۰۲۶-۱۰-۱۴)

- سایت بالا است ولی **هنوز هیچ اپیزود، دسته یا دریچه‌ای ندارد.** فید فعلاً خالی است.
- چون **انتشار بدون دسته ممکن نیست**، اولین کار ساختن دست‌کم یک دسته در پنل است.
- لینک پادگیرها و شبکه‌های اجتماعی در سایت هنوز خالی است (بخش ۹).
- تصویر پیش‌فرض پادکست (کاور ۳۰۰۰×۳۰۰۰ در فید) یک طرح ساده‌ی موقت است، نه کاور طراحی‌شده.

## ۷. انتشار، زمان‌بندی و یادداشت‌ها

**انتشار:**
- **انتشار فوری:** وضعیت «منتشرشده» + تاریخ خالی.
- **زمان‌بندی درست:** وضعیت «**منتشرشده**» + یک **تاریخ آینده**. اپیزود تا آن لحظه پنهان است و سر وقت خودش روی سایت و فید می‌آید
  (در پنل برچسب «زمان‌بندی‌شده» می‌خورد).
- ⚠️ وضعیت «زمان‌بندی‌شده» را **انتخاب نکن**: با آن، اپیزود سر وقت خودبه‌خود منتشر **نمی‌شود** و تا وقتی وضعیت را دستی به «منتشرشده» نبری پنهان می‌ماند.
- پیش‌نویس هیچ‌جا دیده نمی‌شود؛ برای آماده‌سازی و بازبینی خوب است.
- فید فقط اپیزودهای منتشرشده‌ای را دارد که تاریخشان رسیده باشد.
- **اپیزود منتشرشده را حذف و دوباره نساز.** پادگیرها هر اپیزود را با شناسه‌ی داخلی‌اش می‌شناسند؛ اپیزود دوباره‌ساخته‌شده برایشان اپیزود تازه است (تکراری می‌شود). برای اصلاح، همان اپیزود را ویرایش کن. حذف برگشت ندارد.

**یادداشت‌های اپیزود (HTML):**
- تگ‌های مجاز: `<p>`، `<h2>`، `<h3>`، `<h4>`، `<ul>`/`<ol>`/`<li>`، `<strong>`، `<em>`، `<a href="...">`، `<blockquote>`، `<br>`، `<hr>`، `<img>`، جدول. بقیه حذف می‌شوند.
- **زمان‌ها قابل کلیک می‌شوند:** هر زمانی مثل `۱۲:۳۰` یا `1:02:05` در متن، روی سایت دکمه‌ای می‌شود که پخش را به همان لحظه می‌برد. پس فهرست بخش‌ها را با زمان بنویس.
- نمونه:

```html
<p>یک یا دو جمله درباره‌ی موقعیتی که این اپیزود از آن شروع می‌کند.</p>
<h2>در این اپیزود</h2>
<ul>
  <li>۰۰:۰۰ شروع</li>
  <li>۰۳:۱۵ موقعیت: «یک چیزی درست نیست»</li>
  <li>۱۲:۴۰ صورت‌بندی مسئله</li>
  <li>۲۸:۱۰ سؤال و قدم این هفته</li>
</ul>
<h2>منابع</h2>
<ul>
  <li><a href="https://example.com">نام منبع</a></li>
</ul>
```

## ۸. فایل صوتی و تصویر

- **بارگذاری مستقیم** (پیشنهادی): MP3، M4A، AAC، OGG یا WAV، **حداکثر ۳۰۰ مگابایت**. حجم دقیق و مدت خودکار ثبت می‌شوند.
  تا نوار بارگذاری تمام نشده، دکمه‌ی ذخیره کار نمی‌کند.
- برای پادگیرها **MP3 امن‌ترین قالب است** (M4A هم قبول است). WAV و OGG را برای انتشار استفاده نکن؛ حجیم‌اند یا همه‌جا پخش نمی‌شوند.
- **آدرس خارجی:** لینک **مستقیم** به فایل MP3 یا M4A (نه لینک صفحه‌ی دانلود). حجم را سایت خودش می‌گیرد؛ اگر مدت خودکار خوانده نشد، دستی بنویس.
- فایل‌ها روی سرور خود سایت نگه داشته می‌شوند و هر شب پشتیبان گرفته می‌شود.
- کاور پادکست برای پادگیرها باید **مربع، بین ۱۴۰۰×۱۴۰۰ تا ۳۰۰۰×۳۰۰۰ پیکسل**، JPG یا PNG باشد. عوض کردن کاور اصلی کار Claude Code است؛
  کاور اختصاصی هر اپیزود را خودت در فرم اپیزود می‌گذاری.

## ۹. فید و پادگیرها

- **آدرس فید:** `https://darshan.ir/feed.xml` — همین یک آدرس را به همه‌ی پادگیرها بده (Castbox، Apple Podcasts، Spotify، شنوتو و…).
- فید با استاندارد Apple Podcasts ساخته می‌شود و با هر تغییر در پنل خودش به‌روز است. پادگیرها هر چند ساعت یک بار فید را دوباره می‌خوانند،
  پس اپیزود تازه ممکن است با چند ساعت تأخیر در آن‌ها دیده شود.
- **پادگیرها فید خالی را قبول نمی‌کنند:** پیش از ثبت، دست‌کم یک اپیزود منتشرشده با فایل صوتی لازم است.
- مالک فید: مهدی منتظری، mahdii.montazeri@gmail.com (پادگیرها کد تأیید مالکیت را به این ایمیل می‌فرستند).
- وقتی پادگیری پادکست را پذیرفت و لینک صفحه‌ی درشان در آن را داد، **لینک را نگه دار**: باید با Claude Code به نوار «گوش دادن در…» سایت اضافه شود.
  جاهای آماده در سایت: Spotify، Apple Podcasts، Castbox، شنوتو (Google Podcasts هم هست ولی آن سرویس سال ۲۰۲۴ تعطیل شد).

## ۱۰. کارهایی که فقط Claude Code انجام می‌دهد

این‌ها در پنل نیستند؛ مهدی باید از Claude Code بخواهد:

- اضافه کردن لینک پادگیرها و شبکه‌های اجتماعی (لینکدین، اینستاگرام، یوتیوب، X، تلگرام) به سایت
- عوض کردن کاور اصلی پادکست، نام، شعار، توضیح پادکست، دسته‌ی اپل یا هر مشخصه‌ی کلی فید
- تغییر متن صفحه‌ی «درباره‌ی من»، صفحه‌ی همکاری و متن‌های ثابت صفحه‌ی خانه
- اضافه کردن سوابق و مدارک به صفحه‌ی «درباره‌ی من» (این بخش تا وقتی سابقه‌ی واقعی ثبت نشده پنهان است)
- تغییر رمز مدیر، هر خطا یا رفتار عجیب سایت، هر قابلیت تازه

وقتی چنین کاری پیش آمد، یک متن کوتاه و دقیق برای Claude Code آماده کن: چه چیزی، کجای سایت، و متن یا لینک نهایی.

## ۱۱. چک‌لیست انتشار یک اپیزود

1. اگر دسته‌ی مناسب نیست، در «دسته‌ها» بساز (با توضیح کوتاه و متن صفحه).
2. «اپیزودها» ← اپیزود تازه: عنوان، خلاصه، یادداشت‌ها با زمان‌ها، (ترجیحاً) متن کامل.
3. فایل MP3 را بارگذاری کن و صبر کن تا تمام شود؛ مدت را چک کن.
4. شماره، نوع، دسته، دریچه‌ها و برچسب‌ها را بزن.
5. اول با وضعیت «پیش‌نویس» ذخیره کن و همه‌چیز را بازبینی کن (پیش‌نمایش یادداشت‌ها، پخش فایل).
6. برای انتشار: «منتشرشده» + تاریخ خالی (فوری) یا تاریخ آینده (زمان‌بندی). اگر اپیزود تازه باید بالای خانه باشد، «پیشنهادی» را بزن.
7. صفحه‌ی اپیزود روی سایت و `https://darshan.ir/feed.xml` را باز کن و ببین درست آمده.
8. اگر اولین اپیزود است، حالا فید را در پادگیرها ثبت کن و لینک‌هایی که می‌دهند را برای Claude Code نگه دار.
